# JavaScript Projects

These are projects I completed while learning HTML, CSS, JavaScript, responsive web design, GitHub, and website publishing.

## Projects

### Explore Canada One-Page Website
A responsive travel-themed one-page website. It includes section navigation and a JavaScript lightbox image gallery with enlarged images, previous and next controls, and keyboard support.

### City Bites One-Page Website
A second-session one-page project with a completely different food theme and layout. It includes a responsive three-column gallery, separate thumbnail and enlarged image files, a JavaScript modal lightbox, previous/next navigation, and keyboard controls.

### Creative Web Portfolio
An upgraded responsive portfolio website that presents my course work and skills. JavaScript is used for mobile navigation, project filtering, scroll reveal effects, and an automatically updated footer year. The website is prepared for deployment with GitHub Pages.
